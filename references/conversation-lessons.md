# 对话经验索引（已匿名整理）

本页保留会影响后续决策的经验，不保存原始对话、原始附件、聊天人名或共享链接。它不是逐字历史档案，也不包含未提供或未核实的事实。

| 历史场景 | 复用时采取的决定 |
|---|---|
| 去年云表需要登录 | 请提供导出的Excel，未读原件不声称完全沿用模板 |
| 报名表缺队或性别 | 列出缺项，请确认，不能按姓名猜性别 |
| 先做Excel再做网页 | 名单、规则和每项目成绩/排名/得分要一致，不能分叉维护 |
| 汇总总表比报名表多/少人 | 差异注明来自哪份材料；只见姓名不足以补全参赛项目 |
| 同成绩难判定 | 自动预排，交裁判输入正式名次后确认 |
| 项目未确认 | 阶段总分不混入未经核定成绩 |
| 少报名的接力被算0分 | 核对旧减1录取规则，按后续明确选择取消；同步修改文档和表格公式 |
| 团体同分 | 加冠军次数，再逐名次比较所获项目报名人数汇总 |
| 个人奖缺接力成员明细 | 只算个人单项，不凭空分摊接力分 |
| 最佳组织奖 | 保留人工评定，不编造自动化标准 |
| “同时很多人访问会崩吗” | 给轮询请求估算和实测边界，不宣称未测容量 |
| 电脑关机后想继续访问 | 解释本机就是服务器，需持续在线主机才可离线使用 |
| 本机能开但外网失败 | 分开检查服务和隧道，端到端实际验证 |
| 临时链接再次启动失效 | 重新生成与分发，入口读取最新文件，旧标签需更新 |
| 唤醒后仍打不开 | 应用、网络、隧道分别检查，自动启动不是无限在线保证 |
| 分享链接丢口令 | 自动生成角色入口，兼容query/hash，复制失败手动回退 |
| 搜索中文选字被打断 | 避免IME输入期间重绘，轮询不能抢占输入 |
| 启动脚本绑定个人路径 | 重写为相对项目路径和PATH查找，保留可见错误 |
| 全局停止隧道进程 | 只操作本任务核验的PID，避免影响其他项目 |

交付说明应以当前实际文件与测试为依据。旧对话出现过的检查次数、报名人数和手机测试结论不能作为新包的完成证明，故不固化在此包中。
