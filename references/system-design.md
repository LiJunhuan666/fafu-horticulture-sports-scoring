# 系统设计与实现边界

## 结构

浏览器 → Node HTTP 服务 → 本机私有数据目录。浏览器约每2.5秒轮询，不是点对点传数据；多端都访问同一服务端状态，不能各存一份 localStorage 成绩。前端仅本地保存记录员偏好及会话口令。

匿名起点使用 Node.js 内置模块，无第三方运行依赖；`logic.mjs` 排名计分，`server.mjs` 鉴权持久化，`app.js` 交互，`styles.css` 布局。示例图标为本包自带简单SVG，不依赖外部CDN。默认监听127.0.0.1，局域网显式监听0.0.0.0。

界面延续现场工作台：紧凑深灰、松绿色有效状态、浅金色待确认；组别/性别/项目筛选，录入、项目排名、团体榜、个人积分、评奖。桌面侧栏，手机筛选换行及独立编辑弹窗。优先看清状态、成绩和权限，不做花哨大屏掩盖录入任务。

## 接口与权限

| 接口 | 录入角色 | 查看角色 |
|---|---|---|
| GET /api/state | 读取 | 读取 |
| GET /api/export | CSV | CSV |
| GET /api/share | 两种分享口令 | 仅查看口令 |
| GET /api/backup | JSON备份 | 拒绝/不提供 |
| POST /api/result | 录入 | 403 |
| POST /api/confirm | 确认/撤回 | 403 |
| POST /api/award-selection | 裁判选择 | 403 |

未带或带错 Bearer 口令访问数据API返回401。示例查看角色没有匿名公开名单；公开名单需单独取得授权和设计。静态首页200不代表有数据权限。静态资源用白名单，`seed.json`、`data/` 不得直接下载。

链接携带随机角色口令，前端读取后清理地址栏，后续请求使用 Authorization。兼容 `?key=` 与 `#key=`；前者可能进入中间层日志，优先谨慎分发、不要贴公开截图。示例为共享口令权限模型，不是实名账号、分项目权限或学校统一身份认证；长期正式系统应另行设计用户与撤权。

## 写入、同步和审计

每条成绩有version；项目确认有version；评奖选择有全局revision。后端写队列串行处理，旧版本409，要求刷新核对。网络请求失败时显示“保存状态未确认”，不能显示“成功”或不核查便反复提交。连接恢复后主动刷新。

保存用临时文件后rename替换状态，再追加审计。不要声称它具备数据库级事务：若磁盘满或审计追加失败，可能出现状态已写但接口报错，必须重新读取并核对修复。对强一致审计或更多并发需求，可迁移事务数据库。

示例采用单进程文件库；不能多进程共享同一目录或直接上集群。启动时只给用户自己启动的实例执行生命周期管理。

## 交互修复经验

- 搜索输入法：compositionstart/end期间不重建搜索框，不让轮询打断中文选字；保留焦点、选择区与未保存表单。
- 分享复制：剪贴板受浏览器限制时提供可选中输入框手动复制；只读页面不能渲染录入口令。
- CSV：UTF-8 BOM，字段正确转义，引导Excel/WPS打开；防止将 `= + - @` 开头的外部文本作为公式执行。
- 断网显示明确状态，按钮禁用只作为交互辅助，后端仍检查角色和版本。

## 性能边界

N个在线页面、2.5秒轮询约产生 N/2.5 次每秒数据请求，另有静态和写请求。这个估算不是容量测试。用实际名单、电脑、网络及轮询设置做隔离模拟，记录响应时间和错误率，再决定观众访问范围；不要凭CPU型号承诺“几千人不会崩”。可减少观众轮询或发布定时只读导出。现场保留离线表格后备。
